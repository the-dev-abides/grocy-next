# Mealie owns recipes

Grocy has a Recipes area, and Grocy Next must reach parity with Grocy. The
household already keeps its recipes in Mealie, and the human requirements name
Mealie as the source of truth for recipes. We decided that Mealie owns
recipes. Grocy Next does not build a Recipes domain. Grocy Next reaches
recipes through the Mealie link. We chose this because a rebuild of the
Recipes area would cost a milestone and would give the household a second
copy of data that it already keeps in Mealie. The Grocy recipe operations of
the legacy API are a parity exception that the roadmap lists.
