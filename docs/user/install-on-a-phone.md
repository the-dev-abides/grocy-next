# Install the app on a phone

You can install Grocy Next from the browser on an Android phone with Chrome.
The installed app has its own icon on the home screen. It opens in its own
window with no browser address bar.

Grocy Next is a web app. The install does not download the app from an app
store. The app still needs the server. The phone must reach the server to
show data.

## Before you start

- The phone must reach Grocy Next over HTTPS. Chrome installs a web app only
  from a secure address. The camera of the scan screens also needs HTTPS.
- Remove an earlier install of Grocy Next from the phone.

## Install on Android with Chrome

1. Open the address of Grocy Next in Chrome. The review queue opens.
2. Open the Chrome menu. Select `Add to Home screen` or `Install app`. Chrome
   shows one of the two names.
3. The install dialog shows the name `Grocy Next` and the icon. Confirm the
   install.
4. The icon `Grocy Next` appears on the home screen. The icon is a white
   barcode on a blue square.
5. Tap the icon. The app opens in its own window. The status bar is blue,
   and the review queue shows.

The app turns with the phone. You can use it in portrait and in landscape.

## Other devices

- The install on an iPhone or an iPad (iOS) is untested. This page does not
  cover it.
- The camera on iOS and the camera of a desktop computer are untested. The
  page "The scan screens" tells more.
