# Grocy Next

Grocy Next is a replacement for [Grocy](https://grocy.info), the self-hosted
grocery and household manager. The requirements are in
[docs/requirements/](docs/requirements/).

## Status

Pre-alpha. Nothing runs yet. The plan is under review in the
[issues](https://github.com/the-dev-abides/grocy-next/issues).

The project is open to contributors now. If you want to help, start with
[CONTRIBUTING.md](CONTRIBUTING.md).

## Community

- Ask a question in
  [Discussions](https://github.com/the-dev-abides/grocy-next/discussions).
- Report a bug or request a feature in
  [Issues](https://github.com/the-dev-abides/grocy-next/issues/new/choose).
- Read the [Code of Conduct](CODE_OF_CONDUCT.md). It applies in every project
  space.
- Report a security problem as [SECURITY.md](SECURITY.md) says. Do not open a
  public issue for it.
